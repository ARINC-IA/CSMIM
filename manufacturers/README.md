# Manufacturer codes

This folder collects manufacturer codes approved for use with ARINC 853.

Manufacturer codes are used for:
- authentication
- access rules for restricted resources
- manufacturer-specific type definitions

## How to obtain a code

In order to choose your manufacturer code, check in the following order:
1. ICAO Code of your company
2. ARINC 645 MMM Code
3. CAGE Code

If none of the above applies, you shall propose a code of at least 6 letters.

Fork this repository and create your file in this folder, then submit it as a pull request.
You can also contact us via the [group email](mailto:arinc853-csmim@mailman.sae-itc.org).
